# 🧠 DAYTONAA
### Your Personal Data Science Learning University

**Learn. Experiment. Analyse. Build.**

DAYTONAA is a modern, all-in-one Data Science learning ecosystem designed to take learners from absolute beginner to advanced level through structured learning paths, video lectures, digital notes, reference materials, practical assignments, coding exercises, quizzes and real-world projects.

The vision is simple: **Everything you need to learn Data Science, organized in one platform.**

---

## 🚀 Project Overview

Learning Data Science often requires switching between multiple platforms for courses, documentation, books, coding practice and assignments.

DAYTONAA aims to solve this problem by bringing essential learning resources and practical tools together in one centralized, intelligent learning environment.

It combines the experience of an online university, a digital library, a coding workspace and a personal learning dashboard.

## ⚙️ Installation and Setup

### Prerequisites

Install the following:

- Node.js (LTS)
- npm
- Git
- PostgreSQL

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/DAYTONAA.git
```

### 2. Navigate into the project

```bash
cd DAYTONAA
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file using `.env.example`.

Configure the required values:

```env
DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/daytonaa"

AUTH_SECRET="your_secure_secret"

AI_API_KEY="your_ai_provider_api_key"
```

Use the actual environment variable names defined by the application.

### 5. Set up the database

```bash
npx prisma generate
npx prisma migrate dev
```

If seed scripts are configured:

```bash
npx prisma db seed
```

### 6. Start the development server

```bash
npm run dev
```

Open your browser:

```text
http://localhost:3000
```

*Setup commands may be adjusted according to the implemented project configuration.*
